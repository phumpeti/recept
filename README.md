# Receptsamling

Min personliga samling av recept.

Målet är att ha alla favoritrecept samlade på ett ställe i ett enkelt Markdown-format som fungerar bra både i VS Code och på GitHub.

## Innehåll

- recept.md – alla recept

## Husregler

### Struktur

Varje recept ska innehålla:

- Receptnamn
- Ingredienser
- Gör så här
- Källa (om sådan finns)

### Kategorier

Recepten sorteras i följande ordning:

1. Bröd
2. Huvudrätter
3. Smörgåsar
4. Tillbehör & såser
5. Efterrätter

Recepten sorteras alfabetiskt inom varje kategori.

### Formatering

- Rubriker skrivs med Markdown (`##`, `###`).
- Ingredienser skrivs som punktlista.
- Instruktioner skrivs som numrerad lista när det passar.
- Språket i originalreceptet behålls (svenska eller engelska).
- Inga emojis eller onödig formatering.

### Källor

Om receptet kommer från en bok eller webbplats anges källan längst ned.

## Att göra

- [ ] Lägga till bilder.
- [ ] Lägga till fler recept.
- [ ] Kontrollera stavning och formatering vid behov.

## Principer

- Enkelhet går före avancerad formatering.
- Ett recept ska vara lätt att hitta.
- Ett recept ska gå att skriva ut utan problem.
- GitHub ska fungera som backup och versionshantering.
